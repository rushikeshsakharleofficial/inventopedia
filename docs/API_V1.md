# API v1 Contracts — Inventopedia

Base path: `/api/v1`

## Common

### Headers
- `Authorization: Bearer <supabase_jwt>` (all authenticated endpoints)
- `X-Request-Id: <uuid>` (generated by middleware if absent)

### Error Response
```json
{
  "error": "Human-readable message",
  "code": "ERROR_CODE",
  "requestId": "uuid"
}
```

### Pagination
Server-side cursor pagination:
```
?cursor=<opaque>&limit=<1-100>
```
Response:
```json
{
  "data": [...],
  "pagination": { "cursor": "next_cursor_or_null", "hasMore": true }
}
```
